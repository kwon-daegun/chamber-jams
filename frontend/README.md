# Chamber Jams

**Your people. Your playlist.**

Chamber Jams is a collaborative music-room application designed for friends to discover music, share a queue, and listen together through a Telegram Mini App.

## Planned features

- Shared music rooms and invitations
- Collaborative music queue
- Room members can skip tracks without Telegram admin rights
- Real-time playback synchronization
- Ad-free application interface
- Compatible, authorized music provider integrations

## Technology stack

- React
- TypeScript
- Vite
- Java
- Spring Boot
- PostgreSQL
- WebSockets
- Telegram Mini Apps

## Development status

The frontend currently contains an interactive UI prototype. Backend APIs, persistent rooms, authentication, and real music playback are still to be implemented.
